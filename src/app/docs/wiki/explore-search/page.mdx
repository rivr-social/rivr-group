# Explore & search (lives on the global hub)

## What it is

Cross-community discovery — browsing everything on RIVR, searching people and
groups you don't already know, the map, the people directory — is a **global
aggregator** feature. This instance is one sovereign group; it publishes
outward and does not host a platform-wide index.

**There is no `/explore`, `/search`, `/map`, or `/people` route in this
codebase.** Any earlier wiki page claiming otherwise was inherited fiction.

## How to search from here

1. Use the **search bar** in the app header to look for things **within this
   group** — its members, posts, events, and listings.
2. To search all of RIVR, use the search bar's "search everything" / "see all
   results" action, or the bottom nav's Explore and Map buttons. Both navigate
   this tab to the **global hub** (`getGlobalUrl()` → `…/explore?q=…`), because
   there is no local results page to land on.
3. Use the **command palette** (the launcher next to the bottom nav) to jump
   between this instance's own surfaces — Members, Documents, Governance,
   Marketplace, Wallet sub-tabs — without typing a URL.

## Good to know

- Because discovery is global, the way to be found is to **federate**: content
  created here projects to the hub as signed events. See
  [Federation & SSO identity](/docs/wiki/federation-identity).
- The command palette's "Members / Documents / Governance" entries deep-link to
  `/?tab=members|documents|governance`, which the root redirect forwards to the
  primary group page. Only tabs in `ALLOWED_HOME_TABS` are forwarded.
- A map component exists in the source tree but is **not rendered by any route**
  here — do not document it as a user surface.

## Under the hood

- Outward links: `src/lib/federation/global-url.ts` (`getGlobalUrl`), used by
  `src/components/bottom-nav.tsx`, `search-bar.tsx`, `search-header.tsx`.
- Local jump targets: `src/components/CommandBar.tsx`.
- Root-tab forwarding: `src/lib/home-tabs.ts` (`ALLOWED_HOME_TABS`,
  `resolveHomeRedirectPath`) + the `/` 307 in `src/middleware.ts`.
