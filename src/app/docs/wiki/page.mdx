# Wiki

This is the handbook for **this instance** — a single sovereign RIVR group
running its own app, its own database, and its own money rails, federating
outward to the RIVR global aggregator.

Every page answers three questions in the same order:

1. **What it is** — plain language, no jargon.
2. **How to do it** — numbered steps you can follow with the app open.
3. **Good to know** + **Under the hood** — limits and gotchas, then the real
   routes, files, and gates for anyone reading the source.

<Callout type="note" title="Single-group instance">
  This build serves **one primary group**. Opening <code>/</code> issues a real
  HTTP 307 to <code>/groups/&lt;PRIMARY_AGENT_ID&gt;</code> — the group page IS
  the home page. There is no platform-wide explore, search, map, people
  directory, admin console, or locale browser here; those are global-aggregator
  surfaces. Pages below say so explicitly where the distinction matters.
</Callout>

<Callout type="tip" title="Screenshots">
  Pages carry inline screenshot placeholders naming the exact route and
  interaction to capture. The reference deployment for captures is
  <strong>spirit-of-the-front-range.rivr.social</strong>; substitute your own
  instance's host and its primary group id for <code>&lt;id&gt;</code>.
</Callout>
